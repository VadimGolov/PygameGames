## Игра голодная змейка (простая змейка на Pygame)

---
### Описание игры:

Змейка съедает еду (зеленые квадратики), которая появляется на экране и удлиняется пропорционально
количеству съеденного. Игра завершается, когда голова змейки «сталкивается» с краем экрана или со своим телом.

---
### Запуск и опции игры:
Для запуска игры необходимо запустить файл `main.py`. Змейка управляется с помощью клавиш со стрелками.
При запуске змейка находится в центре экрана, игра стоит на паузе и ждёт первого нажатия любой из стрелок
для задания направления движения. После проигрыша можно начать заново — нажать клавишу `C`, на 
клавиатуре или выйти — клавиша `Q`. Пока в игре не реализована пауза и возможность изменять скорость змейки.

---
### Используемые библиотеки:

- Для создания игры используется pygame
- Для генерации случайного положения еды используется randrange из библиотеки random
