## Простой Tetris v 1.0

---
### Описание игры

Простой тетрис на Pygame. Фигуры начинаются «сыпаться» сразу, без паузы.
Только движение, поворот, перемещение, проверка столкновений, и «сгорание линий».
Пока ничего другого нет.

---
### Начало игры:

Для страта игры запустите файл `main.py`. Вы увидите разлинованный в клеточку «стакан»
и падающие разноцветные фигуры. Фигуры управляются стрелками влево/вправо, стрелка вверх — поворот.
Сейчас скорость падения фигур 2 блока (60px) в секунду.

---
### Технологии:

- Для реализации игры используется Pygame.
- Для случайного выбора фигур и их цвета используется функция choice из модуля random.
